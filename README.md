# Fathomless
A simple and relaxing text-based fishing game, with themes **excluding** _cosmic horror_, _psychological terror_ and _existential horror_, and an atmosphere **completely lacking** in _tension_.

Developed as an experiment using my undergraduate thesis project, the [RasPG Framework](https://github.com/RustyGentleman/RasPG-Framework).
Uses sounds from [Freesound](https://freesound.org/). Uses [howler.js](https://github.com/goldfire/howler.js).
